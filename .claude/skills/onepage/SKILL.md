# 단일 파일 웹페이지 제작 규칙 (One-page Webpage)

웹페이지 제작 요청을 처리할 때는 반드시 다음 규칙들을 엄격히 준수합니다.

## 1. 단일 파일 구성
- 웹페이지는 반드시 **파일을 딱 하나만** 만듭니다.
- 별도의 `.css`, `.js` 파일을 분리하지 않고, HTML 파일 내의 `<style>` 및 `<script>` 태그 안에 모두 포함합니다.

## 2. 외부 의존성 차단 (오프라인 동작 보장)
- 구글 폰트(`fonts.googleapis.com`), 라이브러리 CDN, 외부 이미지 등 **외부 주소를 일절 사용하지 않습니다**.
- 인터넷 연결이 끊긴 오프라인 환경에서도 웹페이지가 온전히 로드되고 완벽하게 동작해야 합니다.
- 폰트는 시스템 기본 폰트(`sans-serif`, `system-ui`, `-apple-system`, `monospace` 등)를 활용하고, 그래픽이나 아이콘이 필요한 경우 인라인 SVG 또는 Canvas API를 직접 사용합니다.

## 3. 요구사항 준수 및 불필요한 기능 금지
- 사용자가 **지시하지 않은 기능은 임의로 추가하지 않습니다**.
- 요청받은 핵심 기능과 스펙에만 집중하여 군더더기 없이 간결하고 정확하게 구현합니다.

## 4. 파일 이름 및 폴더 경로 엄수
- 파일 이름은 사용자가 **지정한 이름 그대로** 작성합니다.
- 새로운 폴더나 하위 디렉터리를 임의로 생성하지 않고, 현재 작업 디렉터리에 파일을 생성합니다.

## 5. 로컬 서버 실행 및 접속 주소 안내
- 파일 작성을 완료하면 해당 폴더에서 **로컬 웹 서버를 백그라운드로 실행**합니다.
- 사용자에게 브라우저로 바로 접속할 수 있는 **로컬 서버 주소(URL)**를 명확히 안내합니다.
